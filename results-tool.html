赛果整理工具

浏览器内整理工具，无登录或自动发布。载入现有赛果后合并、更正；相同赛季＋赛事＋Player ID 替换原记录，不重复加分。刷新会丢失未导出的变更。仅导入公开显示名和唯一 Player ID，不含电话、生日或证件。

1. 当前赛季

全部赛事累计，无场数上限。普通 ×1：20 / 15 / 10 / 7（其他 Top Cut）/ 5（其他实际参赛）。双倍 ×2：40 / 30 / 20 / 14 / 10。只取最高档，总分不叠加。未到场、仅报名、取消资格为 0 分。

2. 赛事积分设置

倍率与计分规则必须由 GG 公布后使用。Top Cut 未设置时，CSV 每条第 4 名起的实际参赛成绩必须明确 top_cut。不能按参赛人数猜测 Top Cut。多 Slot / Session 未定义时保持「待确认」；本工具不支持按每个 Slot/Session 重复发分。只有已公布并确认计分方式的 GG Beyblade 排名赛可录入；历史活动不会自动成为积分赛。

3. 导入或更正 CSV

推荐表头：season_id,event_id,date,player_id,display_name,placement,participants,top_cut,attendance

top_cut=true/false；attendance=attended/no_show/registered/disqualified。participants 是实际人数；同场日期与人数一致。缺席或仅报名的 placement 可空。旧六列表头可读，但未知 Top Cut 时需补充 top_cut。season_id 若填写必须与当前赛季一致。一次 CSV 中同一玩家同场多行会拒绝；更正请上传一条最终成绩。导入会先预览替换前后积分。

4. 排名与逐场积分记录

同分按赛季最佳名次、冠军次数，仍相同则并列。成绩应先核实，更正规则及截止时间由 GG 公布。工具不能代替人工核验。

下载后替换 GitHub 的 data/season.json 并提交。不会自动发布。正式启用与完结需填写起止日期。

5. 归档并开始新赛季

先把当前状态设为「完结」。此操作将最终排名、积分规则、赛事设置及逐场原始成绩一起加入 archives，新赛季结果为空。既有历史不会删除。完成后必须导出包含全部历史的 season.json。已归档赛季为只读；历史纠错须另作审核并保留前后版本。
